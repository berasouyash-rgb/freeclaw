## 0. The Contract (why nothing here is fake)

Every worker and every AI surface must satisfy, per run, **all** of:

1. **TRIGGER** — fires only on a real trigger (cron tick, deterministic event, admin manual, or AI-class trigger).
2. **OBSERVE** — reads real state via real tools (Supabase, APIs, provider endpoints).
3. **INVESTIGATE / ANALYZE** — returns `{ decision: act|skip|escalate, reason }` from observed evidence.
4. **REAL TOOLS** — every mutation/query goes through a real tool; no simulated execution, no fabricated results.
5. **REAL STATE CHANGE** — a row inserted/updated, KV ledger entry, alert, or honest `deferred`/`standby`.
6. **INDEPENDENT VERIFICATION** — `verify()` re-reads state; a verifier other than the worker; bare `{ok:true}` is treated as **failure**.
7. **MEASURE** — latency/success/cost metrics recorded from the actual run.
8. **EVIDENCE** — ledger row + optional `tool_evidence` pack with input/output/link.
9. **CONTINUE MONITORING** — supervisor loop detection, pause/rollback, periodic re-trigger.
10. **DISABLE TEST** — "if off for 24 h, X measurably degrades" is written down for every worker.

Banned: fake activity, fabricated metrics, simulated tool calls, workers marked complete without real triggers/actions/verification, UI numbers not derived from backend state.

Every important production failure discovered during this build becomes a **regression test**.

### 20 per-worker audit criteria (final gate, S8)
For each of the 34 registered workers:
1. Real trigger declared (`trigger_types` non-empty)
2. `observe()` reads real state
3. `analyze()` returns decision + reason
4. `execute()` exists and mutates/real-ops only
5. Evidence passed to `execute(dec, ev)`
6. Independent verifier assigned (not self)
7. Bare `{ok:true}` verify rejected
8. Real ledger row per run
9. Budget cap enforced
10. Risk/class correct (A/B/C)
11. Measurement recorded (latency/success)
12. Rollback path present where mutable
13. Loop/pause protections wired
14. Disable test written down
15. Tools used are real (no simulation)
16. Deployment-proof (works on serverless)
17. No fabricated/derived-only metrics
18. Alert/notify path where applicable
19. UI reflects backend state (where surfaced)
20. Regression test exists for its key failure mode
